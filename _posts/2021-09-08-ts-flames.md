# Intro to Pixel Pyrotechnics

In the realm of computer graphics, the flames effect from the demoscene is probably the most iconic. In this article, we will delve into the inner workings, how it's crafted and the very complex mathematics behind it.

## **The Palette**

At the heart of the effect lies its palette - a carefully curated selection of colors that mimic the hues of a roaring fire. Crafting this palette is an art form of itself, as it must strike a delicate balance between realism and practicality.

Typically, the palette includes a shade of red, orange, yellow, and hints of white to simulate the intensity of the flames. These colors are arranged in gradients, allowing for smooth transitions between different stages of combustion.

The 256 colors are organized as follows:

- 32 colors from black to blue (at the top of the flames)
- 32 colors from blue to red
- 32 colors from red to yellow
- 160 colors from yellow to white

``` typescript
private createPalette(): void {

    for (let i = 0; i < 32; i++) {
        // black to blue
        this.palette_.setColor(i, Color.from(new RGBA(0, 0, i << 1)));

        // blue to red
        this.palette_.setColor(i + 32, Color.from(new RGBA(i << 3, 0, 64 - (i << 1))));

        // red to yellow
        this.palette_.setColor(i + 64, Color.from(new RGBA(255, i << 3, 0)));

        // yellow to white
        this.palette_.setColor(i + 96, Color.from(new RGBA(255, 255, i << 2)));
        this.palette_.setColor(i + 128, Color.from(new RGBA(255, 255, 64 + (i << 2))));
        this.palette_.setColor(i + 160, Color.from(new RGBA(255, 255, 128 + (i << 2))));
        this.palette_.setColor(i + 192, Color.from(new RGBA(255, 255, 192 + i )));
        this.palette_.setColor(i + 224, Color.from(new RGBA(255, 255, 224 + i )));
    }
}
```

## **The Flame Algorithm**

The algorithm is one of the most complex in mathematics : the average...

On each frame, the buffer (holding the current pixel color value) is traversed from top to bottom, left to right. At each point, the four adjacent cells value are added together.  
An attenuation is performed so that the fire fades out on the upper cells. The new value is then divided by 4 (the number of cells added), and stored on the cells just above the current one, creating the "moving up" effect.  

The two bottom rows are then filled up randomly with white and black pixels to fuel the fire effect.

``` typescript
// create the flame effect
for (let y = 1; y < this.height_ - 1; y++) {
    let offset = y * this.width_;
    for (let x = 1; x < this.width_ - 1; x++) {
        let value = 0;
        value += this.flames_[offset - this.width_ + x];
        value += this.flames_[offset + x - 1];
        value += this.flames_[offset + x + 1];
        value += this.flames_[offset + this.width_ + x];

        // artificially reduce the flames
        value = value - 3;
        value = (value < 0) ? 0 : value;

        // store the new value above the current pixel
        this.flames_[offset - this.width_ + x] = value >> 2;
    }
}
```

## **The Cherry on the Cake**

Having just some flames at the bottom can be pretty boring after some times. And because the flame buffer is just that, a buffer, nothing forbids you to draw anything in it... as soon as it is white, it will be set alight!

In this demo, we added a 3D wireframe cube that is animated in realtime and drawn in the buffer, giving the effect a cool FireCube.  

How 3D works, and how the FireCube is drawn is beyond the goal of this article, but you can have a look in the [GitHub](https://github.com/oaxley/ts-demoscene/tree/main/files/effects/ts-flames) repo.
